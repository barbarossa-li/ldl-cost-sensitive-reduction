# E0.6：原型预算优先的粒球构造与风险—容量曲线

2026年11月13日。16个已咨询特征族×3训练内折，共48折，与E0.4/E0.5相同训练池及划分；全部预测冻结后统一评分。没有重新评分外层测试集，也没有修改78页论文。

## 新构造与固定对照

每个训练折直接构造K=floor(n×25%、50%、75%、100%)个非空原型，覆盖全部训练对象。候选使用几何二分层次：选择几何方差和标签方差各占一半的标准化优先级最高叶，按特征最远对二分；标签只决定先分哪个叶，不用于叶内样本分配。

对照包括相同二分规则但只用几何优先级、同特征几何下的确定性最远点初始化Lloyd参考实现，以及5个匹配候选组大小直方图的随机划分。所有方法具有完全相同的原型个数和数值数组字节数；随机分组不是聚类性能的唯一对照。Lloyd为明示实现的普通原型基线，不冒充任何论文作者的官方算法。

纯几何和Lloyd对照是在拟合特征几何固定后，不再额外使用标签决定分组；G权重本身仍由训练标签拟合，不能称整个G分组流程完全不使用标签。

U均匀与G全局信息加权几何、Full/cost40两档特征掩码、均匀/组大小投票、先验混合alpha=0/.5都事前固定并全部报告。分组使用加权平方欧氏距离，查询使用原先固定的加权L1中心距离，两者目标不同，未声称求解全局风险最优。

## 数值数组容量

float64/int64预测器数组字节数精确为8×[K(d+q+1)+4d+q]。d为已选特征数，q为标签维数。包括中心、标签、组大小、列索引、缩放、权重与训练均值；不包括Python容器/标量元数据、训练工作内存、缓存或序列化开销，也不是最小可能编码。

预设25%档下，候选相对Lloyd在Full/cost40分别有13/16、12/16族更低；相对随机分组分别有13/16、11/16族更低。说明同容量下存在值得继续核验的层次原型信号，不能只以压缩后相对完整模型有误差代价就否定容量比较。

但标签优先候选相对纯几何二分分别仅6/16、8/16族更低；更高预算也没有一致的标签优先增益。当前证据不能把额外标签优先规则写成稳定独立贡献。更大预算不是所有族上单调降低误差，标签噪声与先验收缩都会影响曲线。

相对完整单点模型加同样的均值先验，25%档在Full/cost40的等族平均Brier分别增加约0.00245/0.00150；因此应表述为精度—容量权衡，而非同时压缩且全面提高精度。纯训练均值的无特征基线也在完整结果和图中保留。

## 完整性与证据边界

全部12720个Brier按独立求和式复算，最大差约1.1e-16；6144个满预算投票/先验/随机种子端点与原始单点预测精确一致。输入与预测哈希、概率和、预算精确性、完全覆盖、训练与外层测试隔离均核验。

这是一套新的预算构造，覆盖全部对象并允许高标签方差叶，与旧严格准入/O1重构算法不同；不继承其对象级约束或旧性能记录。所有族、预算、投票及阴性结果保留，折、种子和预算不作为独立数据集。已咨询训练折也不是独立确认。

## 下一阶段应冻结什么

先保留纯几何二分作为强消融，不预设额外标签优先一定有价值；在相同预算和相同先验下检验信息加权本身及层次表示的作用。接着冻结训练内预算选择规则与外层评价，比较验证风险—容量曲线，而不是挑本轮最优点当作新结果。

正式新稿还需原创性核查和更完整的原型/LDL方法比较。本轮支持的是明确的容量曲线与部分同容量比较信号，尚不足以直接宣称整套新方法优越或达到投稿条件。公开代码、协议、全部汇总及校验；实际行号、分组和逐样本预测只存私有缓存。
