# 训练内机制诊断：权重幅值与粒球读出

2026年11月13日。48折均已完成：16个已咨询特征族，使用v1重复1的训练池前min(192,ntrain)对象做3折。通常128拟合/64验证，SJAFFE约99/50。未读取新外层测试标签；这些仍是开发数据，不是独立确认。

## 找到的问题

原权重W的整行平均值在样本间不同，使源样本的全部距离被共同放大或缩小。即使相对特征形状相同，低整行幅值的源样本也可能更容易成为邻居。N候选把每行W除以其训练Full行均值；零权重行退回全1，子集与查询使用固定训练归一化，不访问查询标签。

这是诊断性干预，不是已验证的新主方法。对照包括U均匀、L旧局部、G训练样本平均后的全局特征权重，以及T：归一化N的5个整行错配排列。全部设置固定zeta=.5，不从验证结果挑zeta或阈值。

## 粒球为什么看起来影响很小

当前表示先找源样本邻居，再将每个被接受叶内的标签替换为该叶均值；查询仍通过原源样本检索，粒球不是直接检索单位。低离散度准入又保证叶内标签彼此接近，因此均值替换往往只造成微小移动。

| 几何 | 读出 | 预测移动能量 | 相对raw的Brier变化 |
|---|---|---:|---:|
| L | ball | 3.2701829e-05 | -0.00007454 |
| L | covered_mean | 0.00077366643 | -0.00054243 |
| L | global_mean | 0.0063001654 | -0.00936578 |
| L | random | 0.0003592557 | -0.00027622 |
| N | ball | 3.0822811e-05 | -0.00012086 |
| N | covered_mean | 0.0011324224 | -0.00053152 |
| N | global_mean | 0.0079725686 | -0.00804570 |
| N | random | 0.00051804903 | -0.00029381 |

L下粒球预测移动能量约为同覆盖均值的4.2%；N下约为2.7%。误差分解ΔBrier=2·mean〈raw−y,δ〉+mean||δ||²在全部记录中通过数值校验；并非移动越大越好，必须同时看移动与残差的对齐项。

对训练表示有精确恒等式：mean_i||R_i−L_i||²=(1/n)Σ_B |B|V(B)。若接受叶满足V(B)≤κV0，则该平均移动≤κV0×coverage。六个实际拟合表示已核验该等式与界。它解释训练平均移动的限制，不单独保证查询风险或泛化误差。

## 验证与边界

2064行开发指标已按另一种求和实现独立复算；预测文件、输入缓存及数据隔离检查通过。零信息回退、行尺度不变性、源方向、仅选定查询列、子集单调性和错配行结构检查均通过。N的分母依赖训练标签，不能自动继承旧几何在重新拟合或标签扰动下的稳定性结果；它也不同于旧严格O1记录。

## 下一版应改什么

先保留G作为必须战胜的特征级信息加权基线，不继续把源样本幅值当作局部有效性。若保留局部信息，需证明相对G与错配控制存在可重复的增益；当前N未达到这一点。

粒球应从事后标签平滑改为可独立检验的查询到原型表示：接受球用特征原型和标签原型表示，未覆盖对象保留残差点。下一阶段应固定同样的特征预算、相同原型容量、同覆盖随机分组及全局收缩对照；只在训练内选择预测规则，另立新版本后再评价。该设计尚未实现，不能提前写成本文已证实的贡献。
