## 实现与等价检查

沿用原始训练统计、原m分母、float64、相同逐属性累加顺序、anchored粒球评价器、256个候选种子对预算、1e-12松弛及从Full开始的完整删除扫描。成本全为1，衡量存储坐标数；不代表降低图像提取成本。

节省内存的方法是保存归一化特征/局部权重，并按子集流式构造一个距离矩阵；C++关闭fast-math及乘加融合。对候选种子对只求精确前256个，边界并列仍按原(-距离,i,j)排序，未修改分裂门槛。3300对象Full距离矩阵和参考误差向量均与原Python实现逐值相同。两个小样本尺度的多个子集，以及18组并列顺序检查通过。选择完成后，原始完整排序评价器对预先指定的第0/511坐标删除候选作独立复算；实际完成并精确匹配的检查数为2。

Linux/AMD EPYC9V74，CPU亲和性3核、cgroup配额2核、内存上限8GiB；C++距离核OpenMP3线程、NumPy BLAS1线程。共享主机资源，不把这一运行的墙钟时间当成跨方法稳定速度优势。上表计时/RSS仅覆盖已有图像特征及拟合统计缓存后的选择进程，含输入、距离矩阵与记录开销；不含图像提取或缓存拟合，不能冒充完整训练流水线峰值。
