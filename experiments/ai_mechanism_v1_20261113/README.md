# Applied Intelligence：16特征族固定机制实验报告

2026年11月13日。冻结协议AI-MECHANISM-v1-fixed-20261113；全部80组预测冻结后统一评分。已知对象级基准实验，不是从未咨询过的独立确认数据；未提供受试者分组泛化结论。

## 完成与完整性

16个特征族×5次划分全部完成，无按结果删除数据集。共1040个预算位置、12560行汇总指标。每个划分3套共享随机成本排序×20/40/60/80%预算，Full计算一次；固定校准zeta=.5、平滑alpha=.5。指标含Brier、TV、KL、JS，主要评价为Brier。

源代码、输入原始文件及转换数组、划分和预测均校验哈希。评分前检查所有预测的维度、非负性、概率和及训练均值回退；原始测试标签没有进入该完整性检查。统一评分后，另以独立写法复核1920个Brier，最大差值为5.55e-17。

## 如何解释

局部几何与分组效果需分开解读：几何改变或粒球相对raw的改善，均不能替代与同覆盖均值和同覆盖随机分组的比较。这里的粒球读出为新残差表示，未覆盖对象保留原标签；它与旧严格O1全局回退读出不同，不能套用旧O1的性能或可行性结果。

固定设置下，粒球相对同覆盖均值的等族平均差未降低；当前结果不支持把接受球均值分组本身写成稳定精度优势。应完整呈现这一结果，再决定是否开发新的训练内表示，而不是在测试数据上改阈值后覆盖本次冻结记录。

局部几何相对均匀几何的等族平均差也未降低；当前固定几何方案的跨族优势尚不足以支持整体优越性表述。

## 后续修改原则

先据本次逐族结果确定可支持的贡献，再单独冻结后续表示开发和外部比较方案。若继续开发粒球读出，只在训练内调整并记录新版本，保留v1作为公开基线；不能根据本轮外层测试结果挑选设置后称为未经查看的验证。
