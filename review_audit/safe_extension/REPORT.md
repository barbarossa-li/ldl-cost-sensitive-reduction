# 整球局部安全扩展：训练内整改验证

日期：2026-10-28。研究目标保持为标签分布信息的低成本约简。本轮只整改参考构造，不宣称已经实现低成本搜索或预测性能改善。

## 构造规则

1. 对同一属性集先运行原构造，将原来合格的叶球固定为锚点。
2. 运行预先固定的备选种子规则（每节点至多 256 对）。原合格叶球不再分裂；新分裂只发生在原先未完成合格表示的区域。
3. 原合格叶球全部保留。新增合格叶球 B 只有在每个成员 i 都满足 `||ℓ_i−mean(L_B)||² ≤ ||ℓ_i−p||²` 时才整球接纳，否则整球继续采用全局均值 p。实现逐对象容差为 1e−12。
4. 不按对象选择不同重建器，不事后拼接最有利的对象预测；局部安全检查是预先定义的整球接纳条件。

## 为什么相对于原构造逐对象不退化

原合格叶球在备选分裂中保持不变，因而这些对象的表示不变。原未合格区域原来全部使用 p；未接纳的新叶仍使用 p，接纳的新叶则由逐成员检查保证误差不增加。三种情况覆盖全部对象。因此每个训练对象相对于原构造的误差不增加；求和即得总重建误差不增加。数值容差下，逐对象最多允许 1e−12 增量，总平均误差也至多增加 1e−12；若 V0>0，依赖度最多降低 1e−12/V0。不能把容差结论称为严格数学不等式。

这是以原构造为锚的扩展保证，原先已接纳的叶球本身不一定逐成员优于全局均值。因此它尚不是一个对全部叶球统一施加相同安全门槛的新构造。若以后统一改门槛，会改变原参考，需要另行定义与验证。

## 不能从这些结果推出什么

安全扩展保证的是同一属性集的新构造相对于该属性集的旧构造，而不是约简子集 P 相对于完整集 A 的保持。正式约简仍须将新完整集参考固定下来，对每个候选 P 检查其全部对象误差；不能只比较总 Γ。

没有进行新约简搜索或测试预测评价，不能据此宣称低成本、泛化改善、参考充分、全局最优或正式方法已经完成。覆盖仍有限，备选分裂的预算和原构造限制仍存在。额外运行原构造有计算开销，不能直接沿用旧复杂度或效率结论。

下一步应将此构造与固定的新完整集逐对象参考结合，运行有明确预算的训练内约简，记录可行性与实际成本；若无法有效降成本，应如实报告，不能放宽局部要求或用测试损失选规则。正文主算法与旧冻结结果尚未替换。
