# E0.5：直接粒球原型检索的训练内开发报告

2026年11月13日。16个已咨询特征族×3训练内折，共48折；使用v1重复1训练池前min(192,ntrain)对象，与E0.4相同。通常128拟合/64验证，SJAFFE约99/50。全部预测冻结后评分，共1776行指标。本轮没有新外层测试评分。

## 实现了什么

接受球以训练缩放空间中的特征均值与标签均值表示，未覆盖样本保留单点。查询直接检索这些原型，而不是先检索全部源样本再平滑标签。固定k=5；不足5个原型时使用全部原型。均匀原型投票和按组内样本数投票两个规则均事先固定并完整报告。

使用U均匀和G特征级全局信息权重：G为拟合训练局部KL权重在源样本上的均值。查询不使用源对象局部权重，也不使用查询标签；仅需选定特征，保留训练Full校准与原始m。参数固定zeta=.5、kappa=.1等，不从内部结果选择投票规则或参数。

预测器独立存储所需特征中心、标签、组大小、所选列、缩放参数与G权重；状态复制后可脱离训练源模型推理。原始单点分支与旧U/G源样本5NN距离及预测精确一致。

## 对照如何匹配

随机分组只打乱被覆盖对象的组归属，保留相同被覆盖对象、残差点、组大小序列、原型槽位键和数值数组字节数；重新计算特征中心与标签均值，使用5个种子。报告每个种子损失的均值，不用平均预测集成或挑最好种子。

另有同一真实球特征中心、但将接受组标签替换为训练全局均值的对照，几何和容量完全相同；还有原始5NN、原源样本半强度粒球平滑、普通半强度全局均值收缩与纯全局均值。

G下逐折数组字节占比平均约0.920，原型槽数占比约0.918；说明接口实现了有限的推理表示压缩，但不是端到端内存节省，也没有降低同一特征预算下的查询特征获取成本。

## 为什么压缩幅度仍偏小

目前仍使用旧的严格接受球规则，未覆盖对象均保留单点，覆盖比例只有约13%–14%。这套低标签离散度准入主要服务于保守重构；直接改成原型检索后，仍不会自动产生较强压缩。该现象支持下一步明确调整研究目标，但没有证明所有粒球表示都无效。

## 验证

概率、维度、输入/预测哈希、训练与外层测试隔离、分组覆盖及空覆盖回退检查通过。1776个Brier按独立求和式复算，最大差约1.1e-16。全单点、相同容量随机、投票、常量特征与零信息、脱离训练源模型的状态推理均有技术检查。

## 下一版设计边界

下一阶段应单独冻结“目标原型预算优先”的粒球构造：在训练内比较固定容量下的风险与存储曲线，与同容量随机分组和可复现的普通原型方法对照。严格接受球方案保留为基线，不能悄悄调松原O1条件后继续沿用其保证。新预算构造尚未实现，也不代表已经建立新的贡献。

直接原型预测不同于旧的训练重构映射，不能自动沿用旧O1可行性或误差保证；本轮只检验训练内预测与表示容量。

本轮是已咨询数据上的开发，不是独立确认或新外部数据集结果；尚未完成新方法原创性核查、外部特征选择器比较及完整投稿稿改写。78页论文、已有v1结果和数据缓存保持不变。公开代码、协议、汇总与校验；实际行号、分组和逐样本预测存私有缓存。
