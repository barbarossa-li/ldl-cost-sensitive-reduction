# GBFRS公开代码候选：可执行核验

日期：2026-10-28。

## 结论

固定版本公开代码不能直接作为正式GBFRS基线准入。本轮复现了五项代码行为，包括候选实现内部的明确失效和需对照正文解释的行为；没有据此断言原论文有同样缺陷，也没有擅自修改原算法后称为忠实复现。当前主稿的正式发表方法对照仍未完成。

来源：https://github.com/AldrinLake/GBFRS ，固定提交 `25a8bc2a8ddf6be13ea8fe773a63def1ca45bc3d`。保存五个Python文件、原LICENSE和来源说明至 `baseline_revision/vendor/gbfrs_candidate/`，供复核；不称已验证的官方作者发布。

## 代码行为与最小见证

| 编号 | 位置与行为 | 已复现证据 | 对比较的影响 |
|---|---|---|---|
| C1 | `GranularBall.split_2balls` 的初始化与聚类使用 `self.X` 全列，而非已选列 | 只选择属性0，四对象的属性0固定为[-1,-.9,.9,1]；把未选属性1从全零改为[0,100,0,100]，分区从[0,1]/[2,3]变为[0,2]/[1,3] | 球构造依赖未选属性。它可能是原方法有意使用的全信息初始化，也可能是实现偏差；没有正文对应，不能擅自删改，更不能称其为严格只用子集的构造 |
| C2 | `InformationGranular.calculate_k_nearest_different_class_samples_that__participate_in_compute_of_lower_approximation` 把非完全异类的距离乘成0，然后对所有位置排序 | 单行标签差[0,.4,1]、属性差[0,.2,.9]、阈值.5时，函数选位置0，不选真正完全异类的位置2 | 与函数注释“从完全异类对象中选最近者”不一致。乘零不能作为排除候选的掩码 |
| C3 | `AttributeReduction` 强制先选两属性，之后无候选耗尽保护 | m=1、m=2均触发 `ValueError: list.remove(x): x not in list` | 对极小维度不完整；实验驱动必须有明确边界处理，不能让缺失结果被静默剔除 |
| C4 | `LabelSignificance` 的共现分母可能为0 | 三对象标签均为[1,0,0]时，两缺席标签配对的分母为0，产生非有限权重 | 这是合法标签分布的边界输入；需要明确定义零分母和标签权重回退规则。不能仅忽略警告继续训练 |
| C5 | 在按维数比例的固定截断后，返回 `selected_features + candidate_features`，并整体加1 | 静态检查确认尾部仍为未评分候选的原索引顺序 | 返回“完整排列”不意味着每个位置都由GBFRS打分产生。当前三数据集m=294/243/24，对应评分前缀长度90/74/11；若评估所有前缀，长前缀结果可能主要反映原索引尾部，而非原方法排序 |

C1和C5是已确认的代码行为与解释边界，不单凭它们判断原方法数学错误。C2是代码与其自身注释不一致，C3/C4是可执行边界失效。全部证据详见 `validation.json`，含逐文件SHA256。

## 执行方式与验证范围

`python review_audit/check_gbfrs_candidate.py` 成功复现全部五项。

为避免GUI、旧编译器导入和演示数据读取，脚本仅通过AST提取原文件中的类与函数定义，注入NumPy/SciPy/scikit-learn及无操作进度条；数学函数体保持原样。没有运行原仓库整个环境，也没有下载或执行其main驱动。没有真实数据训练或性能结果。

## 与论文的对应进展

出版方可检索引言确认：论文评价同时使用粒球—样本相似关系形成的模糊依赖度与局部标签一致性，并区分完全异类和部分异类对象。这与候选代码的总体模块名称接近，仍不足以验证具体公式、阈值、分球坐标、排序截断或边界处理。

作者主页 https://hjtvioller.github.io/ 列出了论文与DOI，本轮读取到的对应条目没有给出全文或候选代码链接，因此未建立公开代码的作者背书关系。检索仍未取得完整正文；不编造公式编号与参数。

本地旧 `baselines_published/run_published.py` 的逐样本高斯模糊下近似仍不能借此称为该论文的“精确强化版”。此次检查也没有授权把有问题的候选代码直接替代旧实现。

## 后续执行选择

1. GBFRS保留为待正文核验的发表方法对照，不生成正式优越性数字。
2. 可独立推进已明确数学定义的通用排序对照：成本顺序、特征—标签平方Pearson相关顺序及相关/成本顺序。名称直接描述规则，不能冠以FSLC、GBFRS或其他发表方法名称。
3. 沿用当前九训练划分和固定逐对象参考，以显式前缀适配器检查可行性并报告请求数、成本及耗时。完整集是可行端点，空集单列；此类结果只能回答通用排序路径与O1的成本比较，不能替代发表方法对照。
4. 后续若修复公开代码，建立独立差异清单与版本名，分别验证原样行为及修复行为，避免结果来源混淆。

当前论文仍未满足发表方法基线与外部预测验证要求。
