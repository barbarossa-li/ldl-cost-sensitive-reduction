# B2 最小开发验证：P/G/A

## 目的和固定协议

隔离粒球依赖度排序的作用，不更改理论定义，不将A直接替换为论文最终算法。
复用 Natural Scene、SBU_3DFE、Yeast_cold 既有第1次、192训练样本划分、成本和三折。
预测器为原有5NN，缩放只拟合各折训练对象；零预测容差。
A固定使用现有默认epsilon=0.05，无调参、无交换细化。
全部方法共用桥接及重启后向删除。本轮没有索引测试/审计对象或评估其标签。
数据来自仓库 download_data.py 所列PyLDL公开源，按原流程逐行归一化标签。

这是已被检查过的训练划分上的开发诊断，不是新的独立确认实验。

## 结果

| 数据集 | P成本/属性数 | G成本/属性数 | A成本/属性数 | G依赖度评估 | A依赖度评估 |
|---|---:|---:|---:|---:|---:|
| Natural Scene | 9 / 5 | 12 / 6 | 9 / 5 | 680 | 3 |
| SBU_3DFE | 14 / 4 | 20 / 5 | 14 / 4 | 323 | 0 |
| Yeast_cold | 0 / 0 | 0 / 0 | 0 / 0 | 0 | 0 |

所有输出满足完整属性集训练内部损失参考，且通过单属性删除不可行检查。
P及G的参考损失与既有修订记录一致（差值小于1e-12）。
A每个正预测改善步骤均独立复核预测效率至少为当前最优值的95%。

- Natural Scene：P/A内部损失0.250779655961，G为0.259264278569，完整集参考0.259591981035。
- SBU_3DFE：P/A内部损失0.0269584437651，G为0.0273676511303，参考0.0274748689376。
- Yeast_cold：三者内部损失0.00623064733444，参考0.00792967591520；直接接受空集，未触发排序。

A与P在三个划分上最终子集及前向属性路径均一致。
Natural Scene的A仅在第4步触发一次粒球候选比较，但选中了P同一属性；SBU没有多候选近优池。
因此A在本轮没有产生不同决策，不能以它优于G推断粒球引导有效。

最终复核运行的同机方法耗时（含独立缓存和惰性几何初始化）约为：Natural Scene P/G/A=1.44/10.93/1.75秒；
SBU为0.91/5.48/0.82秒。此处计时只作开发开销说明，不能作稳定加速比结论。
准确值、评估次数与完整路径见pilot_summary.json及pilot_results/。

## 逻辑检查

search.py已有合成断言通过。check_search.py在100张任意非单调六属性风险/依赖度表上检查300次方法输出，
均满足可行性、单删不可约性、确定性，以及A正增益步骤的局部效率界。
这些检查不证明包含极小、全局最优、最终成本界或外部预测性能。

## 对论文修改的影响

当前证据没有显示粒球依赖度排序优于纯预测排序。G在两个非空划分上成本更高，内部损失也更高；
A的开销较低，但决策等同P。不能据此将A包装成已验证的新贡献，亦不能将既有G结果当作A结果。
暂缓替换正文算法和增加优势声明。

下一步固定规则复用其余既有重复划分，优先检查非空任务中A的实际触发率、路径分歧、最终成本和开销；
不根据审计/测试表现调整epsilon。若决策持续等同P，需重新审视粒球搜索引导的论文主张，不能只扩大实验或调参追求优势。

## 复现

从仓库根目录运行，先按download_data.py取得公开数据（本实验使用其中三个；Natural Scene读取转换后的npy，其余两者直接读取mat）：

```bash
python b2_minimal_validation/search.py
python b2_minimal_validation/check_search.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python b2_minimal_validation/run_pilot.py
```

run_pilot.py保存固定协议、划分及训练数组SHA256、逐方法选择与路径、独立核验标记和实际风险评估计数。
原search.py的risk_evaluations计数不含首次独立完整集回调，报告另记unique_risk_evaluations作为实际唯一评估次数。
