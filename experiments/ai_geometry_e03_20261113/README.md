# Applied Intelligence：覆盖匹配对照与跨数据集方案

2026年11月13日。E0.3使用3个已咨询过的数据集、旧重复1的9个训练内开发折，每折128训练、64验证；训练128内再做三折参数选择。本轮不把已查看过的64行称作独立确认集。

## 这次解决什么问题

原先的随机分组仅匹配分组大小和覆盖总数，仍可能改变具体被覆盖对象；新的对照固定完全相同的覆盖对象、残差对象和每个接受组大小，只重新排列覆盖对象的分组。覆盖均值对照对相同对象使用全局训练均值，未覆盖对象都保留原标签。这样可以区分分组结构、覆盖选择与一般先验收缩。

所有方法共享源方向邻居。固定分析使用校准zeta=.5、收缩alpha=.5；粒球、覆盖均值和随机分组具有相同作用对象及收缩强度。随机5种子报告单个种子损失的均值，不报告先平均预测的集成损失，也不挑最优种子。

## 固定设置下的局部加权结果

Brier越低越好。下表为三个训练内开发折的均值；Full和cost40不能作为6个独立数据集。

|---|---|---:|---:|---:|---:|
| Yeast_cold | Full | 0.00756220 | 0.00755419 | 0.00753914 | 0.00754631 |
| Yeast_cold | cost40 | 0.00697595 | 0.00697502 | 0.00691283 | 0.00694255 |

| Human_Gene | cost40 | 0.01565325 | 0.01564041 | 0.01559074 | 0.01561706 |

这6个局部加权组合中，粒球读出均未优于同覆盖均值或随机分组。因此，当前接受球内均值读出的独立分组优势尚未建立；不能只因相对原始标签略有改善就宣称粒球有效。统一权重U及所有嵌套选择结果一并保留在RESULTS.json。

几何效应另行比较：固定raw读出时，L相对U在Yeast-cold及Human-Gene两种预算下降低Brier，在SCUT-FBP两种预算下升高；方向仍有数据集差异。

## 训练内参数选择

zeta∈{.1,.5,.9}、alpha∈{0,.25,.5,.75,1}。每个权重/预算/读出独立使用相同三折训练内Brier选择参数；所有收缩读出都有15个候选，原始标签读出只选3个zeta。先按全部128个验证对象合并损失，精确同分依次选更小alpha、离.5更近的zeta、更小zeta。参数选择过程不读取最终64行标签。

保存并重新计算2268个训练内候选得分，参数选择全部一致；alpha=0时各对照与raw完全一致。共405行开发结果，全部九个预测包和选择记录先冻结后评分。该复核是工件校验，不增加独立数据证据。

## 正式机制方案v1

16个已知特征族，每族5个对象级随机重复；每个重复3套随机嵌套成本排序×20/40/60/80%预算，Full只计算一次，总80个划分、1040个预算位置。固定zeta=.5、alpha=.5，主要比较U/L几何，以及L下粒球与同覆盖均值读出；同覆盖随机分组和全局均值作为补充对照。Full和alpha=1残差端点单列。

每族先合并重复、成本排序和预算，再作等族权重汇总。所有负结果、失败和族间差异保留；不将预算、种子或重复当作独立数据集。不以测试结果重新挑参数。新划分并非从未使用的独立数据集。

这一版冻结的是机制实验规格和执行器，不是完整论文全部实验协议。GBFRS、IWDLFS/IWCLFS及其他外部方法的选择性能比较、方向性和噪声研究另行冻结，不能把随机子集机制研究当作特征选择优越性证据。

80份私有划分已生成；本地已校验3族6个数组，其他13族26个数组待按缓存优先原则补齐。SCUT-FBP新划分1已完成预测执行检查，但未读取或报告新测试损失；评分器要求80组预测全部冻结。研究规格已经冻结不等于80组实验已完成。
