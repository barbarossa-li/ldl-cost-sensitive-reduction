# Applied Intelligence 新定位、贡献差异与实验设计 v0.1

日期：2026年11月13日。当前状态：设计草案；未执行新大规模实验，未声称已有新性能收益，也不是已完成预注册。

## 目标与主线

目标期刊改按 Applied Intelligence 规划。工作标题：Information-Weighted Granular-Ball Representation for Label Distribution Feature Selection。现有76页稿及其Git历史作为可追溯基线；本阶段不只替换期刊名，也不将旧结果重新命名为新表示实验。

拟检验的主线：局部标签分布信息产生对象—属性相关几何，确定性粒球形成自适应表示，在明确的未见样本预测接口和特征预算下评估作用。O1作为保护型分支及边界案例保留。

## 核心贡献假设

H1：在统一子集、相同预算和同样预测入口下，对象级局部信息权重能带来可重复的表示/预测变化，并在跨特征族上显示优势。

H2：在相同几何与查询邻居下，粒球聚合原型相较raw训练标签和容量匹配随机分区具有实际作用。

H3：几何权重与粒球存在可解释交互；标签扰动下的敏感性可以在明确条件下分析。H1/H2需数据支持，H3的经验部分为探索性；未证明的稳定性不能作为既有定理。

## 已核实的关键差异

IWNRS出版商页面直接链接 dmyuser/algorithm-code。已核对固定提交851ae144c61d51bb3813966a21eb41260c30d2f7中的 informational_weight(data_feature)：按特征熵得到m维属性权重。现有模型的W_ia则来自训练标签局部正则化分布相对全局分布的KL，形成n×m对象—属性权重。这个差异可以作为精确比较的起点；整体新颖性仍需全文逐公式检索，不能直接写“首个信息加权方法”。

GBFRS与FSLSF等当前来源主要为出版商可见摘要/章节。矩阵不把摘要未提及的内容写成“该方法没有”。全文与实现审计完成后再形成正式Related Work。

## 独立评价接口

固定子集配普通欧氏5NN时，改变粒球通常不会改变预测，因此它不能直接检验粒球表示。新候选以“训练源几何检索→训练原型读出”构成完整接口。

raw用L_i；ball_residual对合格已接受粒球使用mu_B，对未覆盖对象保留L_i。旧的全局回退ball_global_legacy单列对照。这样可以区分自适应聚合与回退信息丢失。该读出是新设计，必须先验证，旧O1实验继续按旧定义解释。详细公式、边界与单元检查见 CANDIDATE_INTERFACE.md。

## 主要对比与统计

主对照为U/L权重×raw/ball_residual的2×2；另加G权重的两格。使用20/40/60/80/100%成本上限，3个预定随机排序构造共同嵌套子集，Full去重一次，每外层最多13个共同子集。六格合计上界6240个模型—子集测试评价，实际相同子集会去重。该数量是计划而非已完成实验。

比较U/G/L/S有不同目的：U为均匀L1几何；G检验是否需要对象相关权重；L为候选；S把训练W的整行错配到不同对象，保持权重分布，作为信息对齐负对照。L/S再跨max/mean；U/G的max/mean不能算独立条件。

先对同预算的banks平均，再对预算等权平均，最后重复内族平均。两个主效应做精确符号枚举的双侧配对Wilcoxon，跨两个主检验作Holm校正；交互、其它指标、噪声和资源列为次要/探索性。特征族是统计块，不能把80次重复当80个独立数据集。

主指标为未除q的测试Brier；同时给TV、KL、JS、每族效果、表示覆盖/原型槽位、选择成本和模型/过程资源。已有普通欧氏5NN保留为中性参照，不能把U的L1几何称作欧氏距离。

## 特征选择阶段的安排

先完成候选读出和机制流程验证，再单独冻结E4细则。建议每预算32个共同候选子集、三折训练内CV选P，各拟合折重新拟合权重和粒球；同时报告方法自带读出和中性欧氏5NN对同一选集的表现。CV池最佳选择属于有限候选池实验，不冒充全局搜索保证或原来的严格O1算法。

比较方法至少覆盖GBFRS、IWDLFS/IWCLFS和一项可验证的非粗糙集LDL方法。先核对代码/公式、训练内参数和预算支持；按可复现性确定清单，不按测试名次挑方法。已有三比较方法在旧n=192上的数值不能直接与新n=384结果混用。

## 冻结、缓存和失败处理

E0先在小型例和Yeast-cold/SCUT-FBP/Human-Gene已有训练折进行，不读取新外层测试损失。记录设计变动和原因，之后生成真正的源代码/索引/成本/子集/协议SHA并冻结v1。当前v0.1不能倒称正式预注册。

先查本地与私有Drive缓存并校验。只下载缺失材料；原始数组、预测、标签、拟合权重与个体误差留私有缓存，GitHub仅代码/协议/汇总/来源与校验清单。当前阶段未下载新数据。

所有方法/族/预算保留失败与负结果。资源估计待E0实测单模型时间/RSS后计算；不预先保证某个方法一定胜出，也不因阴性结果删除对照。
