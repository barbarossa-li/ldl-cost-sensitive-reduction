# 有向距离进入预测：训练源到新对象的接口

本轮完成理论接口与实现核验，未扩大正式实验，未修改原训练距离、粒球和依赖度定义，也未替换前面实验的五近邻预测器。

## 固定方向

采用训练对象作为源、新对象作为目标：

$$d^{\mathrm{in}}_{P,T}(x,i)=\overrightarrow\rho_{P,T}(o_i,x)=\frac1m\sum_{a\in P}[(1-\zeta)W_{a,T}(o_i)\Delta_{a,T}(o_i,x)+\zeta G_{a,T}(o_i,x)].$$

源权重完全由训练折拟合。新对象只提供属性，不提供标签，不计算新对象的未知标签权重。选距离最小的5个训练对象，平均其原生标签分布；空属性集使用训练全局均值。

数值属性使用训练最小最大值变换；超出范围时允许外推，不用查询极值重拟合，不额外裁剪。训练恒定属性归零，不凭查询值创造训练中不存在的区分。未知类别的标签轮廓采用训练全局均值，原始类别差异仍按不同取值记1。这是明确的外推约定，不是未知类别的真实标签轮廓估计。

## 与现有理论的关系

| 对象/模块 | 使用的距离或预测 | 是否需要查询标签 |
|---|---|---|
| 原训练粒球构造 | 双向有向距离最大值 | 不涉及查询对象 |
| 前面实验的5NN | 归一化原属性的欧氏近邻均值 | 否 |
| 本轮候选预测接口 | 训练源→查询目标的单向距离近邻均值 | 否 |

把原训练对象作为查询时，接口距离矩阵的转置等于原有向距离矩阵。属性增加时距离非减仍成立，但这不保证预测损失单调。数值查询超出训练范围时，不再声称距离≤1。

粒球训练失真恒等式仍成立，但本接口没有使用粒球成员均值/不合格粒球全局回退的预测规则，因此不能把该恒等式转换为本接口验证损失的结论。有向几何进入预测只是建立了可以检验的联系，不是建立了依赖度与预测效果的等价关系。

## 一个需检验的机制

数值属性的源系数为 ζ+(1−ζ)W。低权重源在同等分离下距离更小。ζ=0.1、m=1时，权重0.8、分离0.2的源距离为0.164；权重0、分离0.3的源距离为0.03。较远的低权重源可能优先入选。

这个例子只是允许系数的代数示例，不是假称真实训练数据拟合出这些权重。它说明源权重不是“越高就越容易作为可靠邻居”的置信度权重。方向选择是否适合预测，还必须检验。

## 内层验证必须重拟合

每个验证折只在其训练补集拟合：最小最大值、带宽、全局标签均值、活跃标签、局部标签轮廓及权重。验证标签只能在预测完成后计算损失。最终外部测试再用完整外层训练集重拟合。

不能沿用外层全部标签拟合的几何来预测内层验证对象。更换预测器后，还必须重新计算完整属性集损失参考及所有候选损失；原欧氏5NN下可行的约简，在新预测器下不一定可行。

## 已完成核验

- 数值、类别、混合三组数据，对3属性全部子集进行24次方向一致性检查，最大误差1.39×10⁻¹⁷。
- 验证未知类别、数值外推、恒定属性、稳定并列排序、概率分布有效性、批量/逐个预测一致、空集回退。
- 一个已有真实Natural Scene内部折：仅128个训练对象拟合几何，预测64个互斥验证对象。修改验证标签后，用原训练索引重新拟合，权重与预测完全一致。
- 没有宣称新的预测损失、优越性或泛化保证。

代码为directed_predictor.py，验证为check_interface.py/interface_checks.json；正文第14节给出接口、性质和限制。

下一步保持子集和参数固定，做逐折重拟合的预测器比较，先检查邻域是否变化、变化是否改善验证损失。通过这一步之后，才能讨论在新预测器下重新运行约简。
