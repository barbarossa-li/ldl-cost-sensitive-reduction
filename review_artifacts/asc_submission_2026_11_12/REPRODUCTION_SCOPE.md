# Reproduction scope

## Checks available in the self-contained packet
1. Independent joint-deletion candidate protocol/summary audit (512 candidates).
2. Arithmetic of seven recorded end-to-end timing rounds.
3. Recorded 2,043-subset / six-endpoint storage-envelope summary arithmetic.
4. Object decision diagnostics recomputed from frozen object records and compared with saved summaries.
5. Feature-family statistical recomputation, including 49,999 permutations, compared with saved results.
6. Presentation figure regeneration from frozen inputs.

## What a PASS does not establish
- No original-data feature-selection or training reruns.
- No independent reconstruction-error-vector replay or raw-data prediction replay.
- No ResNet image inference, dataset download or new hardware timing.
- No independent original-query-pool disjointness check without the external return archive.
- Stored digest-reproduced flags in envelope summaries are checked as records, not independently replayed from underlying vectors.
- No mathematical proof or bibliography validation.

Original datasets, run caches, return archives, model weights and hardware may be needed for deeper reproduction. The repository contains additional experimental code and historical records, but their existence alone does not certify an end-to-end rerun or completeness for every table. The self-contained ZIP's scope is the six checks listed above.

The main benchmark tables and diagnostics have different levels of available evidence. Reviewers should inspect the frozen CSV/JSON inputs and each audit script; this release does not claim every manuscript table is independently regenerated by the quick-start command.
