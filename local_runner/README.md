# Windows：25数据集扩展实验启动器

下载本目录的 **START_25_WINDOWS.cmd**：打开文件页面，点击右上角 Download raw file（下载原始文件）。将它放进一个新建的独立文件夹，再双击运行。保留上一批文件夹和RESULTS_RETURN.zip。

使用已安装的64位Python3.12。第一次启动将自动创建LDL_25_Expanded_Run目录、安装固定版本依赖、从固定GitHub提交下载原始数据和第三方代码，并核验哈希。此后运行与先前扩展包完全相同的冻结协议。需保持联网至数据准备完成；耗时取决于网络，实验本身可能跨多天。

本GitHub交付仅保存项目代码、协议、已有最终评价与完整参考；不再分发原始数据或未明确许可的IW第三方源码。完整旧网格记录继续保存在原RESULTS_RETURN.zip。网上获取的第三方文件仅做原本已记录的换行规范化，必须匹配原冻结哈希。

覆盖25个主数据集及M2B边界对照，复用已完成三数据集九划分。完成后回传LDL_25_Expanded_Run/RESULTS_RETURN_25.zip。中途错误也会尽可能生成部分结果包；再次双击同一个启动器可继续。不要同时启动两个窗口，不要覆盖或修改冻结文件。

安装器固定到GitHub提交并核验SHA256。已验证嵌入包安全解压、七份第三方源码从固定来源恢复及全部文件哈希，并在独立目录重算九个旧参考。Windows完整安装与69个新增实验仍待实际执行。
