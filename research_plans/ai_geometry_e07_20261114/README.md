# E0.7 — 训练池内嵌套预算选择与风险—容量评价

日期：2026-11-14。接续 E0.6，**本轮是开发验证，不是独立确认**。协议、运行器与合成技术检查先提交，再执行基准数据计算。这里的外层指旧训练池内部的外层折，不是原来的外部测试集。

## 固定问题

1. 同一原型预算下，G 信息加权是否优于 U 均匀几何？
2. 同一几何、容量和先验下，几何二分层次是否优于固定 Lloyd 实现？
3. 在训练内选择原型预算后，留出的训练池验证对象上，误差与容量如何变化？
4. 标签优先分裂只作次要对照，阴性结果保留。

16个已咨询特征族，沿用 E0.6 的旧 repeat1 训练池前 min(192,ntrain) 对象及3折；各外层拟合部分再作3折预算选择。每个内层拟合独立拟合缩放、带宽、KL权重及Full校准。Full/cost40、U/G、纯几何二分/标签优先二分/Lloyd、25/50/75/100%预算均固定。统一5邻原型、均匀投票和半强度全局均值先验；该读出规则受此前开发结果影响，不能称完全未见结果的预注册。

对每个预算上限，在内层对象加权平均 Brier 最低的候选中选择预算，1e-12范围并列取更小预算；在全部外层拟合对象上按同一比例重新构造。全部48份外层预测先冻结，才统一评价。原始外部测试行不进入本轮拟合、选参或评分。

## 运行

Python 3.12.14，NumPy2.3.5，SciPy1.17.0 已用于技术检查。

```bash
python -m pip install -r requirements.txt
python check.py
python prepare_data.py --output /absolute/private/data
python runner.py run --data /absolute/private/data --output /absolute/private/e07_run
python runner.py score --data /absolute/private/data --output /absolute/private/e07_run
```

输入 MAT 与转换后 NPY 均校验记录哈希；上游网络、许可和数据源可用性由使用者核对。prepare_data.py 不下载原始人脸照片或模型权重。不要把生成的私有行号、预测和数据缓存提交到公开仓库。中断可续跑已完整并校验通过的case；每个case写完预测后才原子写记录，全部48case完成后写总冻结记录。

## 报告规则

- 固定预算比较匹配原型个数与数值数组容量；每个方法独立选预算的策略比较不保证容量相同，分开报告。
- 每族先按外层验证对象数汇总3折，再等权汇总16族。折、预算、掩码不能充当独立数据集。
- 报告所有固定预算、所有预算上限和阴性结果；不挑最优族或预算作为主结果。
- 容量只计算部署预测器数值数组，不表示训练内存或端到端成本。cost40保留原成本掩码；训练Full校准仍读取完整拟合特征，不宣称训练采集成本降低60%。
- 数据已反复参与开发，即使代码没有折间泄漏，本轮也不能建立独立泛化确认。不声称显著性、新颖性、旧O1保证或达到投稿条件。
- 本阶段没有新增原始外部测试集评分，不改写现有论文。
