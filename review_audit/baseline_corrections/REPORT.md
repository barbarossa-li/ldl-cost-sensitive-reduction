# 对照方法整改：数学组件修复与准入边界

日期：2026-10-28。当前论文方法为 GBIP-O1，目标是固定完整属性参考下的逐对象粒球表示保持。

## 本次已完成

新增独立实现 `baseline_revision/cores.py`；历史驱动、冻结协议与结果均未修改。新组件尚未接入任何正式实验驱动，旧结果不会自动成为修复版结果。

| 组件 | 历史问题 | 新实现及约定 |
|---|---|---|
| 三角隶属度 | 中间项 clip(2-abs(2v-1),0,1) 在 [0,1] 恒为1，三个隶属度不能组成概率划分 | 中间项改为 1-abs(2v-1)，低/中/高中心为0、0.5、1，每个样本的隶属度和为1 |
| 隶属质量互信息 | 不合法的隶属质量可被误当作联合概率 | 校验逐样本概率划分，再按联合质量计算互信息；这是明确的适配组件，不是已核验的论文 FMI 复现 |
| Pearson 相关 | 分母使用平方和乘积，缺少平方根；8个样本的相同列得到0.125 | 使用中心化列范数乘积；常量列与任何列的相关统一定义为0；返回带符号相关矩阵，是否取绝对值必须在选择器协议中单独确定 |
| Ridge | 已标准化输入又减原始属性均值乘权重，混用坐标系 | 仅由拟合训练集估计均值和尺度，中心化标签拟合，标签均值作为不惩罚截距；空属性输出训练标签均值 |
| 分布输出 | 历史内部损失与最终测试的输出处理不同 | 新组件的 predict 统一采用欧氏概率单纯形投影；predict_raw 只供诊断，后续所有验证和测试损失必须调用同一 predict |

单纯形投影是新协议的明确设计选择，与历史截断再归一化不同。所有受影响的调参、选集、验证和测试必须重做，不能复用旧 Ridge alpha 或旧预测结果。

## 尚未准入的论文方法

- FSLC：只修复相关组件；原论文的相关定义、符号处理、相关融合及选择规则仍须逐项对照。
- FMI：概率划分与互信息组件可用；原论文是否采用该三角划分、联合构造与冗余规则仍待核验。
- DSIM：历史代码为核矩阵的 HSIC 风格协方差；没有完成与原论文双相似度邻域模糊熵算法的对应核验。不得沿用 DSIM 原方法复现名称。
- GBFRS/NRS：历史预算说明与实际候选排序不一致；必须区分依赖度优先、增益/成本、成本破同分三个不同规则；不得仅改说明后沿用旧比较结论。

本次没有查验原论文全文，没有将任何上述发表方法判定为可用于正式优越性比较。
