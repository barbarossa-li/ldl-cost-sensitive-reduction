# 25个LDL主数据集与M2B：完整返回核验与数值结果

日期：2026-11-03。全部25个主数据集及单列M2B边界对照，各三次重复，任务全部完成。实验完成不代表所有方法都有有效输出；退化参考和非有限权重按预定状态保留。

## 完整性核验

- 78个数据集划分，其中主实验75个、边界对照3个。17004个参数候选、51012次训练内拟合；主实验16350个候选、49050次拟合。
- 最终返回包CRC通过；源文件、划分、全部选择冻结文件、评价关联哈希、参数三折索引与损失汇总、选参网格最小值均核验通过。初始9划分与首次返回包逐值一致。未在此次重新运行全部预测。
- Movie等18个后续划分保留数值半径修订与精确缓存优化记录，并将运行时记录哈希纳入最终选择冻结。
- 现在已获得Movie第一次重复前两组参数实际检查点：优化复跑的三个折属性序列、逐折损失和总CV均与原完成检查点精确相同，补足此前只有控制台CV对照的验证范围。

## 已发现的边界及缺失

- GBIP-O1在Yeast-alpha与Painting各一个重复遇到预定的degenerate_reference状态，无约简输出；不以零成本或零误差代填。两个数据集均只完成2/3个有效O1输出，因此不计算其完整三重复O1均值。
- Painting与Movie上，IWDLFS/IWCLFS的CV配置各三次重复均无有效候选，固定正文和发布距离lambda=.8配置记录nonfinite_released_weights。这些是无效输出，不作为优劣比较中的成功结果。
- 十个Yeast条件共享特征；数据集数量与独立领域数量分开解释。不把三个重复当作三个独立数据集进行显著性检验。
