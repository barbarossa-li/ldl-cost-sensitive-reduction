# E0.9：容量对齐的原型构造 × 读出规则开发核查

2026-11-14。协议/代码先提交再计算；仍是同16个已咨询特征族、同48个训练池留出折，不新增原始外部测试评分，不改写论文。

## 固定设计

- 构造：旧纯几何最远对二分、10次初始化KMeans++、标准BisectingKMeans、随机单次20轮paper20。
- 容量：固定5中心参照及25/50/75/100%源对象数；所有构造在同一读出/先验下拥有相同K与数值数组字节数。
- 几何：U均匀、G训练信息加权；Full与固定cost40特征掩码。
- 读出NN5：沿用E08的加权L1最近5原型均值；G用于构造及查询。
- 读出ALLP5：所有原型的未加权Minkowski5距离，倒距离softmax加权标签均值；G只影响构造，不用于这一读出查询。
- 先验：alpha0与alpha.5，完整交叉报告。该轮没有新增内层设置选择，也不挑选最优点。

这是两整套读出规则的比较，NN5/ALLP5同时改变距离、邻域范围和聚合权重；不能单独归因为距离或softmax。

## 与原文和E08的关系

U/paper20/K5/ALLP5是E08的LDLKM论文设置重建参照；中心均值的数组求和路径可能产生舍入差异，预测按1e-12核对，部署数组字节要求精确一致。它不是作者发布实现，继承E08披露的缩放、初始化和零距离约定。G或比例预算paper20为明确标名的适配版本，不冒称原论文算法。

NN5共同设置沿用E08的构造种子。K=n统一单点端点，重复特征不足K时依预先披露规则补非空组，保留修复标志。固定5与比例预算如果整数K相同，两个预设槽位仍保留，不当成独立证据。

## 容量口径

同一读出内的构造比较匹配数值字节；不同读出在相同K下未必同字节。ALLP5独立状态包含中心、标签均值、列号、缩放和必要先验，实际数组字节为8*[K*(d+q)+3d+(q ifalpha>0 else0)]。NN5保留E08布局；两者均相对自身单点布局报告字节占比，并另报实测bytes。该数组计数不包括Python/标量元数据、拟合内存或序列化开销，不称最小编码。

ALLP5不保留训练源模型，独立状态可直接推理。原始外部测试行排除于本轮拟合/评分之外；训练校准仍可能读取Full特征，不把cost40称为完整训练采集成本降低60%。
