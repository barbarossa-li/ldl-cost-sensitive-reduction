# 扩大训练规模与重复划分：冻结实验协议

数据为 Natural Scene 原始标签分布（2000对象，294属性，9标签）。排除两轮先前预实验使用过的832个对象，仅使用其余1168个对象。数据来源和哈希沿用 `../pilot/data/sources.json`。

训练规模192、384、576；每个规模5次随机划分；每次测试256对象。同一重复共用测试集，训练集按192→384→576嵌套。各重复之间允许对象重叠，因此均值和样本标准差仅描述划分敏感性，不当作独立样本置信区间。该实验只有一个数据集，也不是新的从未接触过的最终确认性测试。

种子20261100至20261104。每一训练规模重新拟合信息权重、有向距离、粒球和全部属性依赖度。预测器固定为五近邻标签分布均值回归；内部三折，归一化仅在对应内部训练折拟合；最终测试归一化只在外部训练集拟合。代价为原有随机模拟代价1至10，全属性总代价1648，不能解释为真实测量费用。

所有模型参数与上一轮相同：zeta=.1、kappa=.1、beta=1、smin=2、alpha=1、lambda=-1；依赖度容差和预测损失容差均为0。没有对测试损失调整任何参数。

对比全部属性、仅依赖度约束、双重约束启发式。每组划分均先完成全部选择并保存 `selection_before_test.json`，再计算测试指标。输出Brier、KL、TV、JS，属性数、代价、依赖度、合格粒球覆盖率及联合可行性。统计联合可行次数、相对于全部属性的配对测试Brier差值、属性集合之间的Jaccard稳定性。

本轮不做294属性全空间精确回溯；不报告最优发现率或超额成本，因为没有全空间最优代价参考。

复现：在包目录运行 `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python stability/run_stability.py`，完成后运行 `python stability/summarize.py`。每个完成组都有结果检查点，重跑会跳过已完成组。运行耗时共享依赖度缓存，不能作为两个搜索的公平速度排名。

实现保持相同的粒球规则；大规模计算使用fast_granulate.py将最远种子对的枚举向量化，距离最大值与原始对象索引的平局规则不变。40个含距离平局的构造与原实现逐项一致（包括完整划分历史），见fast_equivalence.txt。前两个完成检查点由原实现生成，其余采用等价实现；不比较运行耗时。
