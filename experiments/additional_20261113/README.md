# ASC_LDL 新增实验报告
日期：2026年11月13日。原论文、原实验记录和新增实验分别保留；本报告不把旧记录重算冒充新增原始数据运行。
## 完成情况
已完成27组实际选择运行（3个特征族×3个冻结划分×3种几何）、81次跨几何端点检查，以及官方5500图像从图像到6个既有端点的测试预测重放。所有27组选择先冻结，再统一读取测试标签评分。
原始MAT与转换后数组的SHA-256均匹配原协议。原始方法9次复跑的选集、参考误差向量、最终误差向量和Brier全部精确一致：True。
逐查询误差库记录10,979个运行内不同子集、2,107,968个float64误差值。每条向量散列、数据库完整性、自身O1可行性及终端单删除检查均通过。这个计数跨运行相加，不表示同样数量的独立样本。
## 几何消融
原始版本使用max(ρij,ρji)。对称加权版本使用相同局部信息权重和训练统计，只把互反项改为(ρij+ρji)/2；无权重版本使用原始几何项之和。三者都用原m分母，分别拟合自己的Full参考。
这是有顺序的两个对比，不是完整2×2因果实验。粒球实际输入本来就经过对称化；因此应称“权重的互反聚合方式与去权重对照”，不能宣称独立隔离了所有方向性因素。
| 数据集 | 几何 | 平均保留成本(%) | 平均测试Brier |
|---|---|---:|---:|
| Yeast-cold | 原始双向最大值 | 100.00 | 0.00770576 |
| Yeast-cold | 对称加权平均 | 100.00 | 0.00770576 |
| Yeast-cold | 无权重几何 | 100.00 | 0.00770576 |
| SCUT-FBP | 原始双向最大值 | 55.09 | 0.15510788 |
| SCUT-FBP | 对称加权平均 | 57.69 | 0.15547805 |

Yeast-cold和Human-Gene的三种几何在三次划分中都保留全部属性。SCUT-FBP上，原始/对称加权/无权重的平均保留成本分别为55.09%、57.69%、56.31%；Brier分别为0.15510788、0.15547805、0.15634544。只能描述这三个已知划分，不能据此声称普遍显著优越。
所有27个输出通过自身参考界。跨评价器检查发现：SCUT-FBP第3划分，对称加权选集在原始评价器下有19个对象超界；原始和对称加权选集在无权重评价器下均有6个对象超界。其它跨检查没有超界。可行性确实依赖所定义的评价器与固定参考，不可把三种几何当成同一个可行域。
## 实测训练资源
每次运行使用新Python进程，按顺序运行，BLAS线程数1。记录训练几何拟合与删除搜索CPU时间；峰值RSS为整个进程截至选择结束的峰值，含导入、输入驻留和误差记录缓冲，不含之后的独立邻域检查/SQLite导出。后台环境并非专用硬件，单次墙钟数不能当稳定速度优势。
主机：Linux，AMD EPYC 9V74，CPU亲和性3核，cgroup内存上限8 GiB。以下仅是原始方法9次n=192运行的三次均值，不代表n=3300或全部25任务。
| 数据集 | 拟合+搜索CPU(s) | 峰值RSS均值(MB) |
|---|---:|---:|
| Yeast-cold | 1.716 | 45.50 |
| SCUT-FBP | 101.900 | 219.05 |
| Human-Gene | 2.366 | 52.98 |
为控制输入，三个几何版本都先构建相同的TrainingGeometry缓存；所以raw版本的RSS不是一个专门优化的无权重实现的内存成本，不能据此归因权重存储开销。
