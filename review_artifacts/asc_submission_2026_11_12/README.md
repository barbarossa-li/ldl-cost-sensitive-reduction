# Frozen-record reproduction packet

Download [ASC_REVIEW_REPRODUCIBILITY_v2.zip](ASC_REVIEW_REPRODUCIBILITY_v2.zip), extract it, install `requirements.txt`, and run `python run_checks.py`. Use `--figures` to regenerate historical figures.

The packet contains recorded-candidate, timing, storage-envelope, object-decision and family-statistical checks. Its README describes the inputs and computation represented by each check. [SHA256SUMS](SHA256SUMS) identifies the archive.

For original-data experiments, use the [geometry and replay stage](../../experiments/additional_20261113/) and [complete image-selection stage](../../experiments/official_image_selection_20261113/).

The 13 November manuscript copies and internal editorial integration notes are superseded; their original bytes remain in the [pre-cleanup commit](https://github.com/barbarossa-li/ldl-cost-sensitive-reduction/tree/3a1ad10a7bd79ba3cdde302db56798c9fca1430c/review_artifacts/asc_submission_2026_11_12/). The current manuscript is distributed separately.
